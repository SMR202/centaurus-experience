# Design reference board

Research viewed 9 October 2026. Reference captures are genuine public web screenshots in references/reference-*.png. These are internal study material, not app assets; copyrights remain with their owners. No proprietary logos or interface assets were copied into the prototype.

| Shipped product | Useful idea | Public source |
| --- | --- | --- |
| Apple App Store | A single editorial lead story followed by concise, differentiated discovery sections | https://www.apple.com/app-store/ |
| Airbnb | Recognizable intent choices and an itinerary that exposes each stop | https://news.airbnb.com/product-releases/airbnb-2025-summer-release |
| Nike SNKRS | Give a release its own art direction and clear stateful primary action | https://www.nike.com/SNKRS-app |
| Apple Maps | Route preview before starting; prominent next maneuver and a reachable end control | https://www.apple.com/maps/ |
| Dubai Mall | Place discovery and visitor services in the same navigation system | https://play.google.com/store/apps/details?id=com.thedubaimall |
| Westfield | Put membership privileges beside useful visit information | https://www.westfield.com/en/united-states/app and https://apps.apple.com/us/app/westfield-shopping-app/id1669685692 |
| Mobbin | Attempted search for Apple Maps route-preview patterns | https://mobbin.com/ |

Mobbin returned “requires a paid plan”; no Mobbin screenshots were available or extracted. Public references were used instead. Website captures document the public references, not device testing of those third-party apps. Individual compositions and actual app imagery shown on those public pages informed ideas only.

## Original translation
The Home hero uses real Centaurus architecture. The Club signature is an original three-tower motif. Route blue is reserved for wayfinding. Fictional film art and retailer category studies are original SVG compositions. No competitor screen is reproduced.
