# One-screen design audit

Reviewed real 360px and 390px browser captures on 9 October 2026. See [gallery](SCREENSHOTS.md).

| Area | Decision and result |
| --- | --- |
| Hierarchy | Search precedes one architectural hero; four compact intents precede editorial discovery. Route maneuver and Next dominate active navigation, with End fixed at the bottom. |
| Realism | Real Centaurus architecture and 27 source-backed names establish place. Pending floors remain explicit; demo markers accompany routes, claims, times, points and campaigns. |
| Imagery | Optimized local photo files, licensed fonts, original category art and fictional film posters. Shoes, apparel, beauty and lifestyle now have distinct art. No unauthorized retailer logos. |
| Spacing | 24px gutters, 48px shared controls, mixed rails/rows/hero treatment. Narrow layout and 130% text proxy remain scrollable without observed horizontal page overflow. |
| Contrast | Graphite on ivory, white on ink, route blue for actions. Champagne is decorative; text uses a darker gold token. Photos use a dark overlay under white copy. Full device accessibility certification remains outstanding. |
| Interaction | Native tabs/stacks, labelled controls, selected chip states, sheets with close, reversible save/interest/parking actions, inline reset confirmation and helpful search empty states. |
| Consistency | Shared typography, buttons, notices, rows and icons unify visitor/admin flows. Directions use sans-serif; serif is restricted to editorial headings. |
| Content fidelity | No invented opening hours, stock, reviews, live showtimes, production KPIs or real location claims. Assistant is explicitly scripted. |

Fixed during review: persistent End footer; shorter/clearer route origin; correct parking marker; scrollable destination sheet; category-specific artwork; final dining-offer links. Enlarged text naturally moves lower Home content below the fold; scrolling preserves access. Remaining native checks are VoiceOver/TalkBack, 200% Dynamic Type, device keyboard and safe areas. The prototype is ready for a browser rehearsal; phone presentation sign-off depends on those checks.
